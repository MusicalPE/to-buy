올리기 전 시험

  bash tests/run.sh check   단순 수정(글귀, 색, 여백, 그림 교체) — 코드 검사만
  bash tests/run.sh full    기능 수정(새 기능, 화면 배치, 서버·저장 방식) 또는 애매할 때 — 전체 시험

코드 검사: 자바스크립트 문법(따옴표·괄호 짝), HTML 태그·CSS 중괄호 짝,
           코드가 찾는 id와 단추가 부르는 함수가 실제로 있는지,
           판 번호(index.html APP_VER, sw.js 캐시 이름)가 같은지
전체 시험: 코드 검사 + 화면을 실제로 띄워
           basic   이 기기에서 쓰기 — 담기·쉼표로 여러 개·가게 고르기·기한과 급해요·체크와 되돌리기·다시 담기(길게 눌러 다른 가게에)·
                   고치기·지우기·아래 메뉴(가족·장바구니·설정)·가게 더하기/이름/지우기·기한 단추 고치기·업데이트 소식·여기서 장보기·새로고침 뒤에도 남는지
           family  가족 공간 — 가족 쪽으로 보내는지, 가족이 바꾼 것이 화면에 오는지, 누가 적었는지 표시,
                   초대 QR, 나가면 이 기기 목록으로 돌아오는지
           receipts 내역 — 직접 적기·고치기·지우기, 내 AI 키 넣기, 영수증 찍기 → 읽는 동안 단계·시간 안내(화면을 막지 않음) → 읽은 내용 확인 → 저장하면 사진 버림,
                   영수증이 아닌 사진·AI가 붐빌 때 안내, 달별·가게별 합계, 새로고침 뒤에도 남는지
           share   [공유]로 넘겨받은 영수증 그림 — 서비스 워커가 받아 앱으로 넘기기, 바로 읽기, 맡아 둔 그림 지우기, 전에 읽은 그림이 또 들어오면 저절로 읽지 않기, 같은 내역 안내
           help    사용 안내 — 단추 자리(제목 줄 · 설정 맨 위), 창 열기 · 항목 수 · 닫기(Esc · 닫기 · 확인 · 바깥), 휴대폰에서 잘리지 않는지
           demo    미리보기(?demo)가 뜨고 이 기기 목록을 건드리지 않는지, 넓은 화면·어두운 화면

하나라도 실패하면 올리지 말고 먼저 고칩니다.
판을 올릴 때는 index.html 의 APP_VER 와 sw.js 의 CACHE 를 같은 번호로 바꿉니다.
여기서는 파이어베이스 서버에 붙지 못해 실제 구글 로그인과 실제 AI(Gemini)는 시험하지 못합니다(가족 공간과 AI 답은 흉내 내어 시험).

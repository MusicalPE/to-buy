올리기 전 시험

  bash tests/run.sh check   단순 수정(글귀, 색, 여백, 그림 교체) — 코드 검사만
  bash tests/run.sh full    기능 수정(새 기능, 화면 배치, 서버·저장 방식) 또는 애매할 때 — 전체 시험

코드 검사: 자바스크립트 문법(따옴표·괄호 짝), HTML 태그·CSS 중괄호 짝,
           코드가 찾는 id와 단추가 부르는 함수가 실제로 있는지,
           판 번호(index.html APP_VER, sw.js 캐시 이름)가 같은지
전체 시험: 코드 검사 + 화면을 실제로 띄워
           basic   이 기기에서 쓰기 — 담기·쉼표로 여러 개·가게 고르기·기한과 급해요·체크와 되돌리기·다시 담기·
                   고치기·지우기·가게 더하기/이름/지우기·기한 단추 고치기·여기서 장보기·새로고침 뒤에도 남는지
           family  가족 공간 — 가족 쪽으로 보내는지, 가족이 바꾼 것이 화면에 오는지, 누가 적었는지 표시,
                   초대 QR, 나가면 이 기기 목록으로 돌아오는지
           demo    미리보기(?demo)가 뜨고 이 기기 목록을 건드리지 않는지, 넓은 화면·어두운 화면

하나라도 실패하면 올리지 말고 먼저 고칩니다.
판을 올릴 때는 index.html 의 APP_VER 와 sw.js 의 CACHE 를 같은 번호로 바꿉니다.
여기서는 파이어베이스 서버에 붙지 못해 실제 구글 로그인은 시험하지 못합니다(가족 공간은 흉내 내어 시험).

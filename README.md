# 사야지! To-Buy

가족이 함께 쓰는 가게별 장보기 메모입니다.

- 주소: https://musicalpe.github.io/to-buy/
- 미리보기(로그인 없이 둘러보기): https://musicalpe.github.io/to-buy/?demo
- 로그인 없이도 그 기기에서 바로 쓸 수 있고, 구글로 로그인해 가족 공간을 만들면 초대 QR로 함께 씁니다.

## 할 수 있는 것

- 살 물건을 적고 어디서 살지 가게를 고르면 가게별로 묶임 (쉼표로 여러 개 한 번에)
- 기본 가게는 다이소·이마트, 가게 더하기·이름과 색 바꾸기·순서 바꾸기·지우기
- 언제까지 사야 하는지 적어 두면, 지났거나 오늘·내일까지인 물건이 맨 위 "급해요"에 모임
- "언제" 단추는 오늘·내일·이번 주가 기본, [기한 단추 고치기]에서 모레·토요일·다음 주·이번 달·며칠 뒤를 더하거나 빼기
- [여기서 장보기]: 그 가게에서 살 것만 큰 글씨로 보기
- 체크하면 "산 것"으로 내려가고, 자주 사는 물건은 [다시 담기]로 한 번에
- 가족 공간: 체크가 실시간으로 함께 보이고, 누가 적은 물건인지 표시
- 인터넷이 끊겨도 기기에 두었다가 연결되면 올라감
- 아래 메뉴: 가족(초대 QR) · 장바구니 · 설정(가게 고치기, 기한 단추 고치기, 업데이트 소식)
- 계정·자료 관리: 가족 공간에서 나가기, 계정과 자료 모두 지우기
